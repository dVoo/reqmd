reqmd

A command-line tool that validates requirement specs written in Markdown. One command checks trace links, statuses, version pins, and verification results against a JSON Schema.

check 
$ reqmd check spec/

What one check covers

reqmd check walks a directory tree, validates every requirement against its schema, then runs a second pass over the trace graph.

trace links

Every trace: value must resolve to a requirement ID. Broken references warn; cycles error.

coverage

requires-trace-from expectations are checked against inbound traces. Missing coverage warns.

version pins

~N pins are compared to the upstream version. Stale pins error.

status

Only approved requirements satisfy coverage. draft downstreams are ignored.

verification

CTRF or manual results feed missing-verdict and failing-verdict checks.

disjoint attributes

--disjoint-check requires overlapping values for an array attribute across a trace link.
