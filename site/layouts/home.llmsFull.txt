  llms-full.txt — full plain-text dump of every page on the site.
  Uses .RawContent (the original Markdown source) so structure, code
  blocks, and tables are preserved verbatim. The pass order matters:
  details shortcodes are rewritten to headings first, then remaining
  shortcode markers are stripped, then raw HTML wrapper tags are
  stripped (a targeted alternation of actual HTML tag names so
  angle-bracketed text inside code spans like `<expr>` or
  `<pinned-version>` is preserved). HTML comments are also stripped.
*/ -}}
