#

missing coverage

StripPin removes a trailing ~N version pin from a requirement ref.Returns the bare ref, the pin value, and true if a numeric pin waspresent. A ~ followed by a non-numeric suffix is NOT treated as apin (e.g. "UP-001abc" returns ("UP-001abc", 0, false)) — thismatches the graph layer's parsing and prevents mis-stripping refsthat contain ~ for other reasons.
