IMP-parser-decodeAttrYAML-b0e14ba decodeAttrYAML

#

missing coverage

decodeAttrYAML is the fast path: it parses a small flat YAML map (thecontents of an ```attr block) into map[string]any without building theintermediate YAML document AST that yaml.v3 allocates.

Supported syntax (covers all real-world attr blocks)🔑 value (scalar: string, int, bool)key: "quoted value" (quoted string — quotes stripped)key: (list — following lines are " - item")item1item2comment (ignored)blank lines (ignored)

Values are typed as yaml.v3 would type them:unquoted → string (unless it's an int or bool literal)"true"/"false" → boolinteger → intquoted → string (always, even if contents look like a number)list items → []any of strings

Anything it cannot reproduce exactly — malformed input, nested maps, flowmappings, duplicate keys, or a scalar yaml.v3 would retype (float,timestamp, hex, big integer) — returns errUnsupported so decodeAttrsre-parses the block with yaml.v3. Callers should use decodeAttrs, not thisfunction directly.
