IMP-parser-decodeAttrYAML-b0e14ba decodeAttrYAML

#

decodeAttrYAML is the fast path: it parses a small flat YAML map (the contents of an ```reqmd block) into map[string]any without building the intermediate YAML document AST that yaml.v3 allocates.

Supported syntax (covers all real-world reqmd blocks):

  • key: value (scalar: string, int, bool)
  • key: "quoted value" (quoted string — quotes stripped)
  • key: (list — following lines are " - item")
  • item1
  • item2

  • comment (ignored)

  • blank lines (ignored)

Values are typed as yaml.v3 would type them:

  • unquoted → string (unless it's an int or bool literal)
  • "true"/"false" → bool
  • integer → int
  • quoted → string (always, even if contents look like a number)
  • list items → []any of strings

Anything it cannot reproduce exactly — malformed input, nested maps, flow mappings, duplicate keys, or a scalar yaml.v3 would retype (float, timestamp, hex, big integer) — returns errUnsupported so decodeAttrs re-parses the block with yaml.v3. Callers should use decodeAttrs, not this function directly.
